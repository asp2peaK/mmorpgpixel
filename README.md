# Пожиратель Душ

Браузерная изометрическая экшн-RPG в пиксель-арте. Чистый JavaScript + Canvas, без движков, библиотек и внешних картинок: спрайты и тайлы генерируются в коде, звук — через WebAudio.

## Запуск

Открой `index.html` в браузере — всё в одном файле, сервер не нужен.

Сборка после правок в `src/`:

```
node build.js
```

## Управление

| | ПК | Телефон |
|---|---|---|
| Движение | WASD | джойстик слева |
| Прицел | мышь | автоприцел на ближайшего врага |
| Удар (комбо из 3) | ЛКМ | кнопка с мечом |
| Перекат (неуязвимость) | Пробел / ПКМ | круглая кнопка |
| Души | 1–4 | кнопки с иконками |
| Зелье | Q | кнопка с зельем |
| Взаимодействие | E | кнопка с рукой |
| Меню героя | Tab (I — снаряжение, K — души, J — журнал, M — карта) | кнопка «меню» |

## Что есть

- **Души вместо классов**: 9 мобов + босс, у каждого своя способность и стихия. Дубликаты прокачивают душу до ★3.
- **Реакции стихий**: Разряд, Пожар, Огненный смерч, Пар, Взрыв — работают и против игрока.
- **Химеры**: 10 уникальных скрытых рецептов + процедурные (способность первой души + стихия второй).
- **Немезида**: после смерти на месте гибели встаёт Тень с твоими душами и частью золота.
- **Мир**: город, Опушка, Чаща, Выжженная поляна, Гнилые топи, Костяной погост, Логово Пепельного Волка.
- **Мрак**: тьма со светом вокруг героя, огня и фонарей; туман войны на карте.
- **Лагеря врагов**: частокол, тотем, отряд с вожаком; за зачистку — золото, зелье и душа вожака.
- **Проклятые мобы**: редкие элитные враги.
- **Создание героя**: цвет плаща, кожи, глаз и шарфа.
- **Снаряжение**: оружие, броня, амулет, кольцо; 5 рангов от обычного до проклятого, случайные свойства. Тень при смерти снимает лучшую надетую вещь.
- **Сюжет**: Старейшина в городе ведёт через 8 глав от Опушки до Пепельного Волка; побочные задания у торговца, кузнеца и старейшины; диалоги, трекер заданий, раздел в журнале.
- **Подземелья**: Гнездо Грозы, Утроба Топи, Склеп Костяного Короля — генерируются заново при каждом спуске; ловушки, сундуки, босс со своей душой-ультой. Смерть внутри ставит Тень у входа.
- **Кузнец**: ковка до +10 с шансом провала (золото + осколки) и зачарование вещей душами — стихия на мече, защита на броне, усиление душ на амулете и кольце.

## Задел под мультиплеер

- Способности не знают, кто их кастует: `cast(caster, {dx, dy, tx, ty, stars, el, mult})` одинаково работает для игрока, моба, Тени и призванных существ.
- Свой/чужой определяется только полем `team`.
- Игрок управляется объектом-намерением (`Input.intent()`), его можно присылать по сети.
- Зоны и снаряды — простые данные с полем `kind`, без замыканий.
- Подсистемы общаются через шину событий `Bus`.
